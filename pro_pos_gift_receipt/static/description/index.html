POS Gift Receipt (Qty Only)

A professional Odoo 18 Point of Sale module that enables printing a clean gift receipt containing only product names and quantities, without exposing prices, taxes, discounts, or totals.

Overview

POS Gift Receipt (Qty Only) is designed for retail businesses that want to provide customers with a separate gift receipt after payment. The printed receipt is simplified and suitable for gifting scenarios where pricing details should remain hidden.

Key Features

  • Adds an option in POS Configuration to enable or disable Gift Receipt.
  • Displays a Gift Receipt button in the POS Receipt Screen after payment.
  • Prints a simplified receipt containing only:
    • Product Name
    • Quantity
  • No prices, taxes, discounts, or totals.
  • Compatible with Odoo 18 POS OWL.
  • Preserves the default receipt flow without breaking the original receipt screen.

Use Cases

  • Gift purchases in retail stores.
  • Shops that want to hide item prices from gift recipients.
  • Businesses that need a clean and professional gift receipt experience.
